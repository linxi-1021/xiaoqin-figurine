## 2. 技术路线（Blender 5.1.1，全脚本化、可复现）

| 部件 | 方法 |
|---|---|
| 头 / 躯干 / 四肢 体块 | 球体 + Metaball 融合 → Remesh（体素 0.35 mm）→ 平滑，得到连续皮肤 |
| 脸部五官 | 凹刻/贴面：眼窝布尔 + 眼球独立；眉、嘴用曲线贴面；腮红用顶点色 |
| 头发 | 曲线 + 锥形 Bevel 成束，S 形走向；每束独立对象，最后合并；发梢收细 |
| 熊帽 | 球壳裁切 + 噪波置换（绒面起伏）+ 帽檐实体（倒角曲面） |
| 帽绒 | 几何节点：在帽面按密度散布绒簇（低模簇 + 随机旋转/缩放），可控密度与长度 |
| 熊脸 / 鼻 / 眼 / 睫毛 | 独立几何：压扁球 + 布尔贴合帽面；鼻为超椭圆体；睫毛为薄片曲线 |
| 眼镜 | 圆角方框：曲线 + 矩形 Bevel；镜桥与镜腿用曲线；铆钉为小球 |
| 毛衣 | 躯干外壳 + 罗纹/麻花用位移贴图或几何节点凸条；袖口、下摆独立环 |
| 裙 | 圆台 + 刀褶（阵列 + 径向位移）+ 格纹程序纹理/贴图 |
| 手 | 手掌球 + 五指圆柱（并拢姿态按交接说明），关节融合 |
| 鞋 | 鞋楦放样 + 分层鞋底 + 两条搭带 + 扣 |
| 小熊包 | 圆柱压扁 + 双耳 + 包边压线（曲线）+ 金属环（环面）+ 肩带（曲线贴体） |
| 底座 | 圆柱倒角；底面二维码与刻字用位移/布尔凹刻（二维码矩阵从现有成品迁入） |

统一规范：
- 单位 mm，1 Blender 单位 = 1 mm（scene scale 0.001）
- 每个部件独立对象、独立材质，命名 `P_<部件>`
- 最小壁厚 0.8 mm、最小凸起 0.25 mm（12 cm 树脂打印可读）
- 最终合并为 `Figurine`，保留分件集合以便打印拆分

## 3. 建模顺序（由内到外，先比例后细节）

1. **标定与骨架**：空物体 + 毫米刻度板，锁定上表数值
2. **灰模 blockout**：头球、躯干、四肢、帽壳、裙台、底座——只求比例对，不求细节
3. **头面**：脸型、下巴、眼窝、眼、眉、嘴、腮红
4. **眼镜**：框、桥、腿、铆钉
5. **头发**：前刘海、侧发、后发大束、发梢
6. **熊帽**：帽体、帽檐、熊脸、鼻、蓝眼、睫毛、熊耳
7. **帽绒**：几何节点绒簇（密度/长度分三档：帽体/熊脸/熊耳）
8. **蝴蝶结 + 吊星**
9. **身体与手**：颈、臂、挥手、垂手
10. **服装**：毛衣、袖口、裙、袜
11. **小熊包 + 肩带**
12. **腿与鞋**
13. **底座**：圆柱 + 二维码 + 刻字
14. **装饰**：额角金星、后发两星两花
15. **总装与检查**：合并、法线、壁厚、悬垂、导出

## 4. 防跑偏机制

- **相机表**（与参考裁切同角度）：正面、正侧、背面、45°、帽、脸、眼、手、包、鞋、底
- 每完成一件：渲染同角度 → 与裁切并排 → 六项检查（轮廓/比例/位置/接触/细节数/材质）
- **量化门槛**：剪影 IoU（渲染蒙版 vs 参考蒙版，按包围盒对齐）——部件 ≥ 0.90，整身 ≥ 0.93
- 每件最多 3 轮；未达标回退上一轮并换方法，不硬磨
- 每轮记录：参数、截图、IoU、结论（写入 `建模记录.md`）

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 从零建完整手办工作量大 | 分 15 步，每步独立验收；先灰模锁定比例 |
| 头发/帽绒是最大难点 | 头发用曲线束可控；帽绒用几何节点实例，密度可调 |
| 背面/侧面信息不足 | 以现有效果图与交接说明推断，标注“推断处”待确认 |
| 程序化皮肤偏“圆润” | Remesh 后做局部雕刻式位移（用参考裁切对齐） |
| 打印可行性 | 每阶段跑壁厚/悬垂检查，最终单独出打印检查报告 |
