# 第三组重建规划：小熊包 / 鞋 / 眼镜 / 背面露出（v34）

日期：2026-10-25
输入基准：v33 `小秦_v6右耳残留绒毛清理.blend`（只读，不覆盖）
参考基准：`建模参考_局部细节图集_v1`（v5 效果图裁切）+ `小秦_手办建模交接说明_v1.md`

## 1. 盘点结论（决定技术路线）

| 部件 | 在 blend 中的形态 | 能否按对象整取 | 可用判据 |
|---|---|---|---|
| 小熊包 熊脸贴花 | 独立材质 `Bear bag physical surface projection`（1,876 面）+ `Legacy wrong-side bag face erased`（917 面），范围 x −0.0194…−0.0103、y −0.0142…−0.0054、z 0.0304…0.0415 | 仅贴花 | 材质 + 空间盒 |
| 小熊包 包体 | 无独立材质，属 `PBR_Material`（438,547 面，覆盖全身） | 否 | 空间盒 + 连通性 + 可见性 |
| 鞋 | 独立材质 `Cream leather shoes soft satin finish`（12,425 面），25×18×10 mm，z 0.0096…0.0194 | **是** | 材质直接整取 |
| 眼镜 | 无独立材质，属 `PBR_Material` | 否 | 空间盒 + 连通性（最高风险） |
| 整体 | `textured_mesh.obj` 只有 **1 个主连通岛**（459,478 顶点），包/鞋/镜框与身体、衣服焊在同一张表面 | — | — |

推论：**不能"换对象"，只能"局部开窗 + 生成新件 + 接缝处理"**。这是本次最大的技术约束。

## 2. 技术路线

1. **提取**：材质 → 空间盒 → 背面/内部面剔除，只留可视外壳。
2. **开窗**：只删可视面，保留内部壳；开窗边界做 0.3–0.5 mm 内缩，供新件搭接。
3. **生成新件**：独立对象（倒角圆柱 / 曲线 / 布尔），保持 0.8 mm 以上最小壁厚（12 cm 树脂打印）。
4. **接缝**：新件边缘嵌入旧壳 0.3–0.5 mm，避免缝隙阴影；必要时桥接封口。
5. **必要才布尔合并**：预览用独立壳即可；打印版单独做 union，并检查非流形边。
6. **不动项**：帽绒、熊耳、蝴蝶结、头发主体、底座、二维码与刻字、既有材质参数。

## 3. 分阶段与验收

### M0 基线（不改模型）
- 复制 v33 blend → v34 工作文件，记录 sha256、对象/岛屿/材质清单、包围盒、三角面数。
- 固定相机表（已实测可用，10 机位）：包正面 / 包侧 / 包耳 / 鞋内外侧 / 鞋底 / 镜框正面 / 镜腿侧面 / 背面髋部 / 全身四向。

### M1 鞋（试点，先做）
目标（对照 46/47/48/65）：
- 双层厚底，底厚 ≈ 鞋高 1/3；鞋头围条；两条魔术贴带 + 扣；袜口罗纹。
- 鞋底与底座接触，无穿插、无橙色杂色边。
步骤：材质整取 → 量现鞋 → 重建底/鞋身/带/扣 → 对齐脚部 → 对照。
通过标准：轮廓与参考同角度重合误差目测 < 5%；带宽/扣大小可按 120 mm 实物比例解释；无悬空。
为什么先做：材质可整取、影响面小，用来跑通"提取—重建—对照—回滚"流水线。

### M2 小熊包（主要视觉收益）
目标（对照 41/42/43/59）：
- 近圆饼/短圆柱包体；两只圆耳（直径 ≈ 包径 0.30，10 点/2 点方向）。
- 包边一圈内缩压线；顶部金属环 + 肩带，接触无豁口。
- 包背为素面（不重复熊脸）。
步骤：先量现包体真实外包尺寸 → 提取包体+贴花 → 开窗 → 重建包体/耳/压线/环/带 → 贴合髋部 → 对照。
通过标准：正面轮廓圆整、包耳可辨、包带连续；侧面厚度与参考一致。

### M3 眼镜（最高风险）
目标（对照 12/13/14/16/20/63）：
- 圆角方框（宽:高 ≈ 1.15:1）、框厚等效 2.5 mm、细镜桥、镜腿两颗铆钉。
- 与脸颊/耳部接触，不穿发；镜片按第 7 节确认。
步骤：空间盒提取旧框 → 只删框面（保留脸）→ 新建框/桥/铆钉 → 对齐 → 对照。
通过标准：框型方正度与参考一致；铆钉可见；脸面无破洞、无穿插。

### M4 背面露出
目标（对照 54/59/03）：背面右髋露出素色包背 + 一段肩带。
两条路径（二选一，见第 7 节确认）：改包的位置/角度，或让后发局部让位。

### M5 集成与交付
- 合并新件、重导出 glb；生成 `自动加载数据_<sha12>`；出预览页与两份校验 JSON。
- 更新固定入口 `小秦_最新三维预览.html`（沿用 `publish_latest_entry_v33.cjs` 逻辑）。
- 全新浏览器验证：autoImported=true、filePickerCount=0、控制台 0 错误、解压字节 SHA == glb SHA。
- 归档：四向 + 部位对照图、决策日志。

## 4. 对照机制（防跑偏）

每轮固定四步：
1. **同角度出图**：按相机表拍当前模型，尺寸与参考裁切一致后并排。
2. **六项检查**：轮廓 / 比例 / 位置关系 / 接触与穿模 / 细节数量 / 材质观感。
3. **差异标注**：只在图上标"差在哪、差多少（mm 或比例）"。
4. **决策日志**：记参数改动、原因、结果截图；连续 2 轮无改善 → 回退上一轮改策略。

自动回归（每轮必跑）：
- 未触及对象的顶点哈希不变（帽绒、底座、蝴蝶结、星星、花朵）。
- 包围盒偏差记录；三角面数变化记录。
- 非流形边、开窗洞数量记录（新增洞必须等于预期）。

## 6. 风险与回退

| 风险 | 处理 |
|---|---|
| 开窗后留洞/非流形 | 新件覆盖或桥接封口；记录洞数，交付前必须为 0 |
| 布尔失败 | 预览用独立壳；打印版单独 union，失败则保留分部 |
| 眼镜区域误删脸部 | 先在副本上做删除预览，确认只影响框面再执行 |
| 背面包露出需改发型 | 需你确认；默认只动包的位置/角度 |
| 范围膨胀 | 每阶段只做本阶段清单，发现新问题记入待办，不当场改 |
